## Overview

**Portfolio V4** is a high-performance, fully responsive personal portfolio website engineered exclusively with **semantic HTML5** and **modern CSS3**.

- **100% Pure Static Architecture**: Zero React, zero Vue, zero Node.js/npm dependencies, zero build pipelines, and zero runtime scripts.
- **Instant Cloud Deployment**: Directly deployable to GitHub Pages, Cloudflare Pages, Netlify, Vercel, AWS S3, or Google Cloud Storage.
- **Frictionless Local Viewing**: Double-click `index.html` to open directly in any web browser without local web servers or terminal commands.

## GitHub Pages Deployment Instructions

To host this website for free on GitHub Pages:

1. In your GitHub repository (`https://github.com/amsaikatcmt/amsaikat`), navigate to **Settings** > **Pages** (under the "Code and automation" section in the left sidebar).
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Under **Branch**, choose `main` (or `master`) and folder `/ (root)`, then click **Save**.
4. Within 1–2 minutes, your website will be live at:  
   **`https://amsaikatcmt.github.io/amsaikat/`** (or `https://amsaikatcmt.github.io/` if repository is named `amsaikatcmt.github.io`).
